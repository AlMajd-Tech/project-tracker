# project-tracker

A small practice terminal program for tracking projects.
Written in Python 3 using only the standard library. Data is saved in `projects.json`.

## Project fields

- `title`
- `client`
- `expected_due_date`
- `owner`

## Features

Only these two. Do not add others unless asked.

1. Create project
2. List projects

## Commands

- Run: `python3 tracker.py`
- Verify: `python3 -m unittest`

## Never

- Do not open `.env`
- Do not run git commands
- Do not add new dependencies
